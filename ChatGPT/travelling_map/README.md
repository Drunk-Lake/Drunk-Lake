# 城市旅游地图与景点攻略

本目录收录 18 个城市和地区的交互地图及 TXT 攻略。地图可以按区县、景点名称和已核实的景区等级筛选，并查看景点介绍与资料来源。

## 打开地图

GitHub Pages 部署完成后，在下方城市目录点击「地图」即可在线查看交互地图。

1. 如需在本地查看，从仓库下载 ZIP 并解压，或者克隆 `ChatGPT` 分支。
2. 双击 `travelling_map` 下任意城市文件夹里的同名 `.html`。使用页面里的城市切换菜单查看其他地区，解压后请保留各城市文件夹的相对位置。
3. 同目录的 `.txt` 按区县整理景点推荐理由与攻略。道路底图等在线地图资源需要网络，页面内嵌的景点资料与行政区信息可继续查阅。

## 数据说明

各地图保留了景点、行政区划和底图的来源及署名。A级用于表示中国内地景区质量等级。攻略中的票价、开放时间和预约信息以景区最新公告为准。

新增地图时，在 `travelling_map/` 下创建同名城市目录，放入 HTML 和 TXT，同步更新各地图里的城市切换菜单与此索引。
